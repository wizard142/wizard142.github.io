Privacy policy

Effective date: 16 October 2026

This policy describes the Wizzy Rant Studio production tool and these public information pages. The tool is intended for the owner of the Wizzy Rant YouTube channel, rather than a public sign-up service.

Information the tool accesses

  • Google authorization: OAuth client credentials, access tokens and an offline refresh token, used to act with the channel owner's consent.
  • YouTube account information: the authorized channel identifier, its upload identifiers and publication status, and the metadata needed to prepare and verify uploads.
  • Aggregated channel analytics: available views, engaged views, average viewing duration and percentage, retention reports, like and comment counts, and subscribers gained. These reports do not give this tool individual viewers' identities.
  • Optional owner exports: aggregate viewed-versus-swiped-away measurements that the owner explicitly supplies from YouTube Studio.

The tool does not request access to Gmail, Google Drive, account passwords or payment information. It does not fetch individual viewers' identities or the text of their comments.

Public video discovery: The tool also requests public video identifiers, titles, publication times, source channels, native popular-chart/search results and raw view counts through the YouTube API. These are discovery leads rather than proof of a video’s claims. Public discovery observations are retained for up to three days in the private workflow state. The tool does not calculate a custom virality or views-per-hour metric from these API counters, and this discovery data is not provided to Codex. Source footage for production must be supplied separately as approved reusable media; the API is not used to download YouTube audiovisual content.

How information is used

Google-account information is used to confirm the intended channel, upload and check the owner's videos, identify uncertain or duplicate uploads, and produce private performance comparisons. Analytics help the owner assess editorial choices and support local checks for any controlled upload-frequency experiment.

Google-account data, OAuth credentials and Google analytics summaries are not provided to Codex for script generation. Public news excerpts and original editorial material are processed by Codex separately. Google API data is not used by this tool to train generalized AI models.

Storage and service providers

The cloud workflow runs in the owner's private GitHub repository. YouTube OAuth credentials are stored as GitHub Actions secrets. Channel records, publication journals and aggregate analytics are stored in a private state branch. Production logs and review artifacts have a configured one-day retention period.

Google and YouTube process authorization and API requests. GitHub stores the private workflow data and executes the job. Google-account data is not sold, used for advertising, or shared with unrelated third parties.

Retention and deletion

Operational account records remain until the owner removes them. The owner can pause the workflow, remove its GitHub secrets and stored records, and manage any remaining repository history or backups. Revoking Google access prevents future authorized access but does not automatically erase previously stored records.

Access can be reviewed and revoked through Google Account permissions. For support or data-deletion requests, use the support email shown on the application's Google consent screen.

These public pages

These pages use no analytics scripts, advertising, forms or application cookies. GitHub Pages may process technical request information under GitHub's privacy statement.

Google and YouTube policies

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Google's own handling of information is described in the Google Privacy Policy.

Changes

This policy will be updated when the tool's data practices change. Any new use of Google-account information requiring consent must be disclosed before it is enabled.
