# Website images

Project imagery:

- `projects/clipfix.png`: public ClipFix repository, `assets/screenshot_dark.png`.
- `projects/chess.png`: public Difficulty Ladder Chess repository, `assets/screenshot-game.png`.
- `projects/genie.jpg`: browser capture of the public Genie repository's `thumbnail.html` promo artwork.
- `projects/zenge.jpg`: browser-rendered preview of the owner's Zenge sign-in design, with blank form fields. No account information or backend code is included. The preview uses a taller canvas to keep the title and form distinct.
- `projects/python.svg` and `projects/linux.svg`: original illustrative graphics for the general learning entries; captions identify them as illustrations.

Channel imagery:

- `channels/wizzy-rant-avatar.jpg` and `channels/wizzy-rant-banner.jpg`: the owner's public @Wizzy-Rant channel artwork, retrieved October 18, 2026.
- `channels/wizzy-posts-avatar.png`: the owner's previously prepared Minecraft-style Wizzy Posts profile artwork. The site labels this channel as in preparation.

Images are served from this repository, with descriptive alternative text (or empty alternative text where the adjacent channel name already provides the label). Project screenshots use contain sizing so their interfaces are not cropped. Below-the-fold images load lazily. No external image service, account credentials, or additional runtime dependency is required.
